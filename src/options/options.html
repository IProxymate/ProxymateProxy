Профиль

Это протокол разговора с прокси, а не список сайтов. Обычный HTTP-прокси нормально обслуживает и https-сайты — через CONNECT.

HTTPS-прокси требует, чтобы сервер сам принимал TLS-соединения. Такое умеют единицы: если сайты перестанут грузиться — вернитесь на HTTP.

SOCKS4 не умеет разрешать имена на стороне прокси: адреса сайтов разрешает ваш DNS-провайдер, и он видит, куда вы ходите. Если прокси поддерживает SOCKS5 — выберите его.

SOCKS с логином и паролем Chrome через API расширений не поддерживает — авторизация будет проигнорирована.

Пробный запрос уходит через проверяемый прокси, текущее соединение при этом не разрывается — остальной трафик идёт как шёл.
